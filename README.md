# Número Secreto - Alura

## Descrição do Jogo
O jogo "Número Secreto" é um desafio onde o jogador deve adivinhar um número aleatório entre **1 e 100**. O jogo fornece dicas para ajudar o jogador a descobrir o número correto.

## Como Jogar
1. O jogo escolhe um número aleatório entre **1 e 100**.
2. O jogador insere um palpite.
3. O jogo informa se o palpite é maior ou menor que o número secreto.
4. O jogador continua a adivinhar até encontrar o número correto.
